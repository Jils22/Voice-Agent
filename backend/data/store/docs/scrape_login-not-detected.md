# Login Not Detected

Facing “Login Not Detected” in Suvit? It may be due to internet issues, closed app, or mismatched logins. Follow this guide to troubleshoot and resolve it.

### Login Not Detected

![1.png](https://strapi.suvit.io/uploads/1_69064c1cdc.png)

---

### Reason 1: Internet Connection Might Be Interrupted

#### Solution 1:

* Open **System Tray** → **Quit** the application.
* **Right Click** → **Quit**.  
  ![2.png](https://strapi.suvit.io/uploads/2_c414a28356.png)
* **OR** Open **Task Manager**.
* Select **Suvit** → **End Task**.  
  ![3.png](https://strapi.suvit.io/uploads/3_1c93df6301.png)
* **Re-open** the Suvit Desktop Application.

---

### Reason 2: Different Login on Website and Suvit Desktop Application

#### Solution 2:

1. Check **Login Details** on the Website and Application:

   * **Website**: Check details under **Profile**.  
     ![4.png](https://strapi.suvit.io/uploads/4_0d1d8d815d.png)
   * **Application**: Go to **Settings** → **Profile**.  
     ![5.png](https://strapi.suvit.io/uploads/5_275251e360.png)
2. Login again with the correct **Username and Password**.

---

### Reason 3: Suvit Desktop Application Is Not Open

#### Solution 3:

* Simply **Open** the Suvit Desktop Application.

---

### Reason 4: You Are Using Remote Desktop Connection

#### Solution 4:

* **a.** Change the Tally port. [Click here](https://help.suvit.io/articles/how-to-check-tally-port-or-change-port-in-tally-prime) for Steps.
* **b.** Change the port number in the Suvit Desktop Application. [Click here](https://help.suvit.io/articles/how-to-configure-tally-port-with-suvit) for Steps.
