# Determine Your Windows 32/64-bit Version

Suvit supports both 32-bit and 64-bit Windows. Learn how to check your system’s OS version and download the correct Suvit application accordingly.

Follow the below steps for to identify the [window version](https://support.microsoft.com/en-us/windows/32-bit-and-64-bit-windows-frequently-asked-questions-c6ca9541-8dce-4d48-0415-94a3faa2e13d)

#### Step 1: Open File Explorer

* Open a File Explorer window by pressing **Windows key + E**.

#### Step 2: Access This PC

* On the left, right-click **This PC**.

#### Step 3: Open System Properties

![6this%20pc.jpg](https://strapi.suvit.io/uploads/6this_20pc_47ecf80eea.jpg)

* In the context menu, select **Properties** to open the System Properties window.

#### Step 4: Check System Type

![764%20bit.jpg](https://strapi.suvit.io/uploads/764_20bit_ab41d99907.jpg)

* In the System Properties window, find your **System type**, which lists your operating system and CPU type.
