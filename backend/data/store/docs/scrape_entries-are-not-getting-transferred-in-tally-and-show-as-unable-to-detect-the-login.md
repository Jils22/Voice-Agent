# Unable to Detect Login

After clicking "Send Transaction to Tally", if no progress shows, the app may have timed out. Quit it from Task Manager and reopen to continue smoothly.

### Entries Not Transferring to Tally – "Unable to Detect Login"

#### Step 1: Identify the Error

![1 img.PNG](https://strapi.suvit.io/uploads/1_img_664bfa1c63.PNG)  
If you see this error, follow the steps below.

#### Step 2: Close Suvit Tally Connector

![2 img.png](https://strapi.suvit.io/uploads/2_img_3cb8a01ba8.png)

* Open **System Tray** → Right-click **Suvit App** → **Quit**.
* OR open **Task Manager**, select **Suvit**, and click **End Task**.

#### Step 3: Restart Suvit Tally Connector

```
Confirm that the login ID is the **same** in both the **Suvit Web Browser** and the **Tally Connector Application**.
```

![3 img.png](https://strapi.suvit.io/uploads/3_img_a18562e58c.png)

* Restart the **Suvit Desktop Application** and Click on **Settings.**

#### Step 4: Save Setting

![3.1 iimg.png](https://strapi.suvit.io/uploads/3_1_iimg_04b306db0b.png)

* Click on **"Save Settings"**

#### Step 5: Use the Refresh Option

![4 img.PNG](https://strapi.suvit.io/uploads/4_img_780c38cd3a.PNG)

* If the issue persists, click the **Refresh** tab.

#### Step 6: Wait for Data to Process

* Allow **2 to 3 minutes** for the process to resume and sync entries to **Tally**.
