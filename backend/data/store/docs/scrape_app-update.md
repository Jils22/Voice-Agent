# App update

### Quick Troubleshooting Steps (Suvit / Vyapar TaxOne)

#### Step 1: Configure Tally Settings

![1.webp](https://strapi.suvit.io/uploads/1_3428d3745c.webp)

Open Suvit Desktop → Settings.

![4.webp](https://strapi.suvit.io/uploads/4_06397b2a2a.webp)

* Copy details

#### Step 2: Close Running Applications

![3.webp](https://strapi.suvit.io/uploads/3_30917b2f6d.webp)

* Open **Task Manager** (**Ctrl + Shift + Esc**).
* End **Suvit** or **Vyapar TaxOne** process.

---

#### Step 3 Uninstall Suvit

![6.webp](https://strapi.suvit.io/uploads/6_c845e1f4c5.webp)

* Press **Windows + R** → type **appwiz.cpl** → **Enter**. Or Go to control panel to uninsatall
* Select **Suvit/Vyapar Taxone** → click **Uninstall**.

---

#### Step 4: Restart System

* Restart your **PC / Laptop**.

---

#### Step 5: Delete Suvit Files

![Screenshot (1625).png](https://strapi.suvit.io/uploads/Screenshot_1625_fbd399e812.png)

* Press **Windows + R** → type **appdata** → **Enter**.

![Screenshot (1638).png](https://strapi.suvit.io/uploads/Screenshot_1638_c366c9b1c3.png)

* Open **Local** folder and delete **Suvit**-related folders.

---

#### Step 6: Reinstall Suvit

![2.webp](https://strapi.suvit.io/uploads/2_19a37e4869.webp)

* Download and install Suvit from here: [Learn more](https://help.suvit.io/articles/how-to-install-suvit-desktop-tally-connector-on-any-system)

---

#### Step 7: Configure Tally Settings

![5.webp](https://strapi.suvit.io/uploads/5_65b00a051a.webp)

* Open **Suvit Desktop** → **Login** → **Settings**.

![4.webp](https://strapi.suvit.io/uploads/4_06397b2a2a.webp)

* Paste the details which you have copied earlier.
* Ensure **Tally Port** matches Tally configuration.
* Click **Save Settings**.
