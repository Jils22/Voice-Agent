# Unable to add company from Secondary user account ?

Facing issue in adding company from your Secondary account in Suvit can be due to permission limitations.

---

### Unable to Add Company from Secondary User?

If you are facing the issue of being unable to add a company, it means that you are using a secondary user ID and do not have the necessary rights to add a company.

![1image.png](https://strapi.suvit.io/uploads/1image_2e0e63902f.png)

### Steps to Resolve the Issue:

#### Step 1

* Connect with the **primary user account holder**, which is your main account. Only the primary account holder has the rights to add a company.

#### Step 2

* If you don't have direct access to the primary account, ask the primary account user to provide **full access** to your account from the role that has been assigned to you.

#### Step 3

* Ensure that the "Assign Company" option is set for full access. This option should be checked when the user was created. If it was left blank, it could restrict access, preventing the secondary user from adding the company.
