# How to create a Party Name ledger from the banking module.

A new ledger from Suvit for your Tally. It is the same feature as in Tally, with the same fields to be filled up while creating a ledger.

---

### New ledger creation from **Suvit**

* On the transaction page, a feature is available to create a ledger in **Suvit** for your Tally. In case you do not have some ledgers in Tally, and while selecting ledgers in **Suvit**, you want to avoid going into Tally and creating it, you can always create one from **Suvit** itself.

### Single Party Name Creation

#### Step 1: Create Ledger

![1 cretae ledger.png](https://strapi.suvit.io/uploads/1_cretae_ledger_c4a281244d.png)

* Check for and click on the **"Create ledger"** tab in the top right corner as highlighted in the above image.

#### Step 2: Add the Ledger

![1create ledger bank.png](https://strapi.suvit.io/uploads/1create_ledger_bank_fd8b474040.png)

* Fill up the required fields; **Name** and **Ledger Type** are mandatory fields to be filled, and then click on "Add" as shown in the above image.
* Also, if the party is **GST** registered, simply enter the **GST number** and click on get data:

### Bulk Party Name Creation

#### Steps to follow

![2.png](https://strapi.suvit.io/uploads/2_2ed94cfd67.png)

**1** → Click on **"+" Plus** button as shown in below image.

![3.png](https://strapi.suvit.io/uploads/3_1e2a151038.png)

**2** → Choose between **Create Without Review** or **Review before creation**
- Create Without Review will create the Party name directly
- Create Review before creation will help you to check its details and allow modification before creating the Party Name.
- Now you will have **Ledger Creation Screen**

**3** → **Click** on **Create**

![4.png](https://strapi.suvit.io/uploads/4_5c32fb73bf.png)

* After making required changes like Under type, bill by bill, registration type and other details.

**4** → Select your Data

**5** → Click on **Save**

**6** → Click on **Back to banking**

![5.png](https://strapi.suvit.io/uploads/5_80cf7759de.png)

**7** → Whenever you send data to Tally. Party name will create automatically

```
You need to send at least one transaction from Suvit to create ledger in Tally.
```
