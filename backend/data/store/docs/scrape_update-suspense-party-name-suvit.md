# How to Change or Update Suspense Party Name in Suvit’s Banking Module

Learn how to update or replace the Suspense Party Name in Suvit’s Banking Module by selecting the transaction and assigning the correct ledger.

#### Step 1 - Login to Suvit

Login into [Suvit](https://in.suvit.io/signIn).

#### Step 2 - Navigate to Banking Module

* Click on **Explore Now** under Data Entry Automation.
* Go to the **Bulk Upload** from the Dashboard.
* Open the **bank statement** in **Banking** where the **Suspense Party Name** needs to be updated.

#### Step 3 - Identify the Suspense Entry

![1.png](https://strapi.suvit.io/uploads/1_01fb30d41a.png)

* **1** → Look for the transaction where the **Suspense Ledger** has been assigned.
* **2** → **Select** Transactions.
* **3** → Update with required **Party Name**
* **4** → Click on **Save** to update the entry.

### Try this if the entry has already been sent to Tally.

#### Step 1 - Navigate to Banking Module

![2.png](https://strapi.suvit.io/uploads/2_b851e2248e.png)

* **1** → Look for the transaction where the **Suspense Ledger** has been assigned.
* **2** → **Select** Transactions.
* **3** → Click on **Delete** Button

#### Step 2 - Delete Entry

![3.png](https://strapi.suvit.io/uploads/3_b4c5a83a46.png)

* **4** → Select **Delete from Tally** option
* **5** → Click on **Delete** Button

![4.png](https://strapi.suvit.io/uploads/4_41cbf1b69e.png)

* **6** → Wait for the conformation message
* Now **Repeat** [Step 3 - Identify the Suspense Entry](https://help.suvit.io/articles/update-suspense-party-name-suvit#step-3-identify-the-suspense-entry) from above to update **suspense** transcation.

Now, the **Suspense Party Name** has been successfully updated in Suvit. 🚀
