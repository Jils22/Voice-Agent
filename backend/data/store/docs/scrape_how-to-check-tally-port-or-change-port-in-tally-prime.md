# How to check Tally port or change port in Tally Prime

Using Suvit on multiple systems with multiple Tally instances? Ensure each Tally ODBC port is unique for smooth and uninterrupted connectivity.

### How to Check or Change Tally Port in Tally Prime

Follow these steps to check or update the **Tally Port** in **Tally Prime** for seamless connectivity with **Suvit Desktop Application**.

#### Step 1: Open Tally Prime Help Menu

![28assets2F-MLkVtZ4H8RJl1C0LTcA2F1.PNG](https://strapi.suvit.io/uploads/28assets2_F_M_Lk_Vt_Z4_H8_R_Jl1_C0_L_Tc_A2_F1_a568cec660.PNG)

**1.** Press **F1: Help** to access the **Configuration** menu.
**2.** Select **Settings** from the Help menu.  
**3.** Click on **Connectivity**.

#### Step 2: Access Connectivity Settings

![29assets2F-MLkVtZ4H8RJl1C0LTcA2F2.PNG](https://strapi.suvit.io/uploads/29assets2_F_M_Lk_Vt_Z4_H8_R_Jl1_C0_L_Tc_A2_F2_c483abf731.PNG)

* Navigate to **Client/Server Configurtion** and Click **Enter**.

#### Step 3: Configure ODBC and Set Port Number

![30assets2F-MLkVtZ4H8RJl1C0LTcA2F3.PNG](https://strapi.suvit.io/uploads/30assets2_F_M_Lk_Vt_Z4_H8_R_Jl1_C0_L_Tc_A2_F3_62d44c6cd2.PNG)

* Set **Tally Prime Act** as **Both** to enable both local and remote access.
* Enable **ODBC** by setting it to **Yes**.
* Set the **Port Number** as **9050** ✍ (You can choose any number between **9000 to 9999**).

#### Step 4: Restart Tally Prime

![31assets2F-MLkVtZ4H8RJl1C0LTcA2Fyes.PNG](https://strapi.suvit.io/uploads/31assets2_F_M_Lk_Vt_Z4_H8_R_Jl1_C0_L_Tc_A2_Fyes_e20b927ddf.PNG)

* Select **Yes** to restart Tally Prime and apply the changes.

#### Final Step: Configure with Suvit Desktop Application

* Once Tally restarts, open your company in Tally.
* Configure it with the **Suvit Desktop Application**.
* Follow this [Step to Guide](https://help.suvit.io/articles/how-to-configure-tally-port-with-suvit) to connect with **Tally Connector**.
