# How to enable API access in GST Portal?

To enable API access and connect Suvit with the GSTN portal from your account, follow the below process.

### How to Enable API Access?

**Follow these steps to enable API access:**

#### Step 1: Log in to the GSTN Portal

* Go to [gst.gov.in](https://www.gst.gov.in/) and log in to your **GSTN account**.

#### Step 2: Navigate to My Profile

![1api-access-my-profile.png](https://strapi.suvit.io/uploads/1api_access_my_profile_d3399fa945.png)

* Click on your **name** in the top-right corner.
* Select **My Profile** from the dropdown.

#### Step 3: Access API Management

![2manage-api-access.png](https://strapi.suvit.io/uploads/2manage_api_access_55c73de442.png)

* In the **Quick Links** section, click on **Manage API Access**.

#### Step 4: Enable API Access

![3api-access-confirm.png](https://strapi.suvit.io/uploads/3api_access_confirm_a9d4af38e6.png)

* Click **Yes** to enable API access.
* Select the **Duration** from the dropdown.
* Click **CONFIRM** to save the changes.
