# How to Enable and Enter Cost Centre in Suvit Banking Module

Learn to enable and manage the Cost Centre feature in Suvit Banking. This guide covers setup and offers manual and bulk methods for efficient data entry.

### How to Enable Cost Centre in Banking Module

* Make sure you have Cost Centre in Tally and Ledger sync has been done.
* There are two methods to enter Cost Center in Suvit

#### Step 1 - Open the Transaction Screen:

![1 Open Bank Statement.png](https://strapi.suvit.io/uploads/1_Open_Bank_Statement_aa0ac07c00.png)

#### Step 2 - Go to **Settings** → **Configurations**:

![2 setings.png](https://strapi.suvit.io/uploads/2_setings_f269e9a0f0.png)

#### Step 3 - Enable Cost Centre:

![3 enable voucher.png](https://strapi.suvit.io/uploads/3_enable_voucher_321c856234.png)

### Cost Centre

* One row will be appear for Cost Centre as shown in below screen.

![4 cost center.png](https://strapi.suvit.io/uploads/4_cost_center_288c7e5d44.png)

### How to enter Cost Centre

#### Method A - Manual Select

* Click on the cell, type and select cost center one by one

![5 A.png](https://strapi.suvit.io/uploads/5_A_2b5502bd40.png)

* After entering the data **SAVE** it.

#### Method B - Bulk Select

* Filter your data if required.

![6 1.png](https://strapi.suvit.io/uploads/6_1_da66dab1f3.png)

* Select your entry and assign Cost Centre as shown in below image

![6 2.png](https://strapi.suvit.io/uploads/6_2_4d3b176a12.png)

* Cost will be get selected

![6 3.png](https://strapi.suvit.io/uploads/6_3_4303b02595.png)

* And **Save** the data.
