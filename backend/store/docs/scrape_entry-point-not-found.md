# Application update - How to solve entry point not found issue

Facing issues while running the .exe file? Follow the steps in this guide to troubleshoot and ensure the Suvit application runs smoothly on your system.

### Entry point not found issue

* This Error occur due application update was not properly

#### follow the steps below:

![app error.PNG](https://strapi.suvit.io/uploads/app_error_87d835ef63.PNG)

### Steps to Resolve:

#### Step 1. Close the Suvit Process in Task Manager

![Screenshot (1622).png](https://strapi.suvit.io/uploads/Screenshot_1622_a1d087565c.png)

* Open Task Manager by pressing **Ctrl + Shift + Esc**.
* Locate and select the **Suvit** process.
* Click on **End Task** to close it.

#### Step 2. Uninstall the Suvit Application

![Screenshot (1623).png](https://strapi.suvit.io/uploads/Screenshot_1623_ba55bc2945.png)

* Open the Run dialog by pressing **Windows Key + R**, type **appwiz.cpl**, and press Enter.

![Screenshot (1624).png](https://strapi.suvit.io/uploads/Screenshot_1624_e2097a5bf1.png)

* In the **Programs and Features** window, locate **Suvit** in the list of installed programs.
* Select it and click on **Uninstall** to remove it from your system.

#### Step 3. Delete Suvit-Related Folders

![Screenshot (1625).png](https://strapi.suvit.io/uploads/Screenshot_1625_fbd399e812.png)

* Open the Run dialog again by pressing **Windows Key + R**, type **appdata**, and press Enter.

![Screenshot (1638).png](https://strapi.suvit.io/uploads/Screenshot_1638_c366c9b1c3.png)

* In the Local folder that opens, search for any **Suvit**-related folders and delete them.

#### Step 4. Reinstall the Suvit Application

![Suvit (12).png](https://strapi.suvit.io/uploads/Suvit_12_1bada8dbbe.png)

* Once all Suvit-related folders are removed, reinstall the program. How to download application [Learn more](https://help.suvit.io/articles/how-to-install-suvit-desktop-tally-connector-on-any-system)
