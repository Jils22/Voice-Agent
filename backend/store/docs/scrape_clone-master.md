# How to Clone Ledger Master and Copy Stock Item Master in Suvit

Learn how to copy a Ledger Master and Stock Item Master in Suvit. This guide helps you duplicate existing records quickly for efficient data management

### **Navigation**

* Login into [Suvit](https://in.suvit.io/signIn).
* Click on **Explore Now** under **Data Entry Automation**.

### **Steps to Clone Ledger Master**

#### Step 1 - Select the Ledger to Clone

![1.png](https://strapi.suvit.io/uploads/1_dfcbe00e53.png)

* **1** → Go to the **Master** Module
* **2** → Select \*\*Ledger \*\* from the available options.
* **3** → Choose the **ledger** you want to clone.
* **4** → Click on the **Clone Ledgers** option.

#### Step 2 - Select Company to Copy

![2.png](https://strapi.suvit.io/uploads/2_646e2f0628.png)

* **5** → Select **Company**
* **6** → Click on the **OK** button to copy the Ledgers(Party Name).

Now, the **Ledger Master** has been successfully cloned in Suvit! 🚀

---

### Steps to Copy Stock Item Master

#### Step 1 - Select the Stock Item to Copy

![1i.png](https://strapi.suvit.io/uploads/1i_2a9d0a545a.png)

* **1**→ Go to the **Master Module**.
* **1** → Go to the **Master** Module
* **2** → Select \*\*Ledger \*\* from the available options.
* **3** → Choose the **ledger** you want to clone.
* **4** → Click on the **Clone Ledgers** option.

#### Step 2 - Select Company to Copy

![2i.png](https://strapi.suvit.io/uploads/2i_4f807e61d8.png)

* **5** → Select **Company**
* **6** → Click on the **OK** button to copy the Ledgers(Party Name).

Now, the **Stock Item Master** has been successfully copied in Suvit! 🚀

```
Whenever any single transaction has been sent to Tally from Suvit, the copied **Party Name** and **Stock Item** will also be created in Tally.
```
