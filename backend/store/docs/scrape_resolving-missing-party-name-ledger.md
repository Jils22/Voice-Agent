# Auto Ledger Creation - Missing Ledgers in Banking

Learn why party name ledgers may be missing in Suvit’s Banking module. Fix spelling issues or create new ledgers using Bulk Upload or the Create Ledger option.

### Reasons for Missing Party Name Ledger

![1.png](https://strapi.suvit.io/uploads/1_edff01f145.png)

#### There are mainly two reasons:

* **1** → The uploaded Excel sheet contains a new party name ledger, or there is a spelling mistake in the party name ledger.
* **2** → The data was previously sent, but the party name ledger was deleted and then synced again. As a result, Suvit recognizes it as a missing (new) party name ledger.

### Solution

* Create the party name by using [Create Ledger](https://help.suvit.io/articles/new-ledger-creation-from-suvit) option.

**OR**

* Create the party name by using [Bulk Option](https://help.suvit.io/articles/new-ledger-creation-from-suvit#bulk-party-name-creation) option.
