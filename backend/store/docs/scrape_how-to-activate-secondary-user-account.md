# How to active deactivated user (Secondary user)

Your account may be deactivated after multiple failed logins. Log in to your primary account and reactivate it from the User Management section in Suvit.

### There are two method:

### Method 1: Forgot Password

* Use [Forgot Password](https://help.suvit.io/articles/how-to-reset-your-suvit-account-password)

![1 forget img.png](https://strapi.suvit.io/uploads/1_forget_img_0e68ce2964.png)

### Method 2: Activate from by using **Main Account**

#### Step 1: Sign in to Suvit

![Sign In](https://strapi.suvit.io/uploads/1signin_e8217ce2f5.png)

* Go to Sign in into [Suvit.io](https://www.suvit.io/) and log in with the **Primary Account**.

#### Step 2: Navigate to User Management

![User Management Settings](https://strapi.suvit.io/uploads/2_Usermgt1_f39217c13b.png)

* From the **left side menu bar**, Go to **User & Roles**

#### Step 3: Reactivate the User

![2 img user.png](https://strapi.suvit.io/uploads/2_img_user_fd997aaded.png)

* On the **User & Roles** page, find the **User List** under the user section.

![Reactivate User](https://strapi.suvit.io/uploads/3_Usermgt2_899a304e7b.png)

* Click on the **Deactive** button next to the user, and it will change to **Active**, reactivating the user.

#### Step 4: Advise the User

* Inform the reactivated user to log in using the correct User ID and Password.
* If they have forgotten their password, instruct them to **Reset Password**.

```
**Note**: By completing these steps, the user account will be successfully reactivated, and they can log in again.
```
