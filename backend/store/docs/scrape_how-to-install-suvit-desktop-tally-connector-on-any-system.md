# How to install Suvit desktop tally connector on any system?

A step by step guide to install Suvit desktop tally connector application on any system which is above windows 7 which has OS of 32 Bit & 64 Bit.

### Instructions:

* By default 64 Bit application will be download automatically.
* How to check the system is [32 bit or 64 bit](https://help.suvit.io/articles/determine-whether-your-computer-is-running-a-32-bit-version-or-64-bit-version-of-the-windows-operating-system)
* To download 32-bit Suvit Desktop Application kindly e-mail us on [[email protected]](/cdn-cgi/l/email-protection) to receive the download link.

#### Step 1: Download Connector

![2.webp](https://strapi.suvit.io/uploads/2_1741f7e613.webp)

* Login into [Suvit](https://in.suvit.io/signIn)
  ![1.webp](https://strapi.suvit.io/uploads/1_c92174df0c.webp)
* Go to **Help & Resources**
* Click on **Download**

#### Step 2: Installation

![3.webp](https://strapi.suvit.io/uploads/3_22e1d9b34d.webp)

* **Double-click** the on downloaded file(application)
* Click **"Run"** if prompted and wait for the installation to complete.

#### Step 3: Log In

![Apk Image.png](https://strapi.suvit.io/uploads/Apk_Image_7fab90df6f.png)

* Enter your Suvit **Username** (Mobile number or E-mail id) and **Password**.

```
**Note:** Follow any on-screen instructions to configure your Tally with Suvit after successful login.
```
