# "Complete" status after processing the statement

The statement is in "Complete" status, so one can begin working and select ledgers for the transaction to send the data in Tally.

When the status **"Complete"** appears, the statement has been **successfully** processed. Click on it to open the extracted statement. You may now begin by **selecting and saving** ledgers for your transactions. Once the ledgers have been saved, you can send the saved data to Tally.

![1.webp](https://strapi.suvit.io/uploads/1_6eb8b80c0a.webp)

* You can select ledgers both **individually** and **in bulk**.
* Use various filters to make the process of selecting ledgers easier and faster.
