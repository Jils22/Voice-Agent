# How to create party name in bulk using transaction screen

Working with a new company? No need to create Party Names in Tally. Use Suvit’s Auto Ledger feature to create and manage them directly and efficiently.

### **Transaction Screen**

#### **Step 1 - Orange Triangle**

![1. orange triangle.png](https://strapi.suvit.io/uploads/1_orange_triangle_67fb35af04.png)

* Data in orange appears due to mainly **three reasons**:

##### **A. Name in Excel Sheet is Different from Name in Tally**

![a. party name in excel.png](https://strapi.suvit.io/uploads/a_party_name_in_excel_274170b5a8.png)  
![B party name in tally.png](https://strapi.suvit.io/uploads/B_party_name_in_tally_4374e30194.png)

##### **B. Ledger Sync is Pending**

* If names are the same, **Ledger Sync** might be pending.  
  [How to Sync Ledger? [Click Here](https://help.suvit.io/articles/how-to-sync-ledger)]

##### **C. New Party Name List**

#### **Step 2 - Plus Icon**

![2 plus button.png](https://strapi.suvit.io/uploads/2_plus_button_da5da78784.png)

* Click on the **Plus Icon** to create the party names shown in **orange**.

```
Always cross-check the spelling in Tally and the Excel sheet.
```

#### **Step 3 - Create Auto Ledger**

![3. Choose option.png](https://strapi.suvit.io/uploads/3_Choose_option_0fb518aa50.png)

##### You will get the option to create a Party Name:

###### **A. Create Without Review**

* This option is **not recommended**. It will create a Party Name directly.

###### **B. Review Before Creation**

* This option allows you to review and modify details such as **Under Type**, **Bill by Bill (On/Off)**, and other changes.
* If the **Excel sheet** contains a **GST Number** that is mapped, you can create a Party Name using the GST Number with the following options:

###### **C. Trade Name**

* A trade name may also be called a "Doing Business As" name.

###### **D. Business Name**

* This appears on **legal documents** and **government forms**.

##### Then, click on the **Create Button**.

#### **Step 4 - Ledger Transactions**

![4 transaction screen.png](https://strapi.suvit.io/uploads/4_transaction_screen_aa50ab2a7d.png)

* **4:** Party Names are ready to be created.
* From here, you can change the **Under Type** of the Party Name.
* **5:** If you create a Party Name using a **GST Number**, it will fall under **Regular Registration Type**. If it is created without a GST Number, the Registration Type will be **empty** (you can change it to **Regular**, **Unregistered**, etc., as needed).

#### **Step 5 - Save**

![5 select and save.png](https://strapi.suvit.io/uploads/5_select_and_save_a2b189cbbb.png)

* **6:** Select all your data.
* **7:** Click on **Save** to save it.

#### **Step 6 - Back to Sales**

![6 back to save.png](https://strapi.suvit.io/uploads/6_back_to_save_b40d829702.png)

* **8:** Click on **Back to Sales**.

```
At least one bill/transaction must be sent from the Sales/Purchase module to Tally to create all Party Names in bulk.
```
