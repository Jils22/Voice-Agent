# How to Enable and Enter Voucher Number in Suvit Banking Module

Learn to enable and enter Voucher Numbers in Suvit Banking. This guide covers settings and two easy methods to input voucher numbers efficiently.

* As of now we are not fetching Voucher Number from the Bank statement (Pdf & Excel).
* There are two methods to enter Voucher Number in suvit.
* Make sure that Voucher numbering method of **Payment, Receipt & Contra** is **Manual**. How to check and setup[Click Here](https://help.tallysolutions.com/tally-prime/accounting/voucher-types-tally/)

### How to Enable Voucher Number in Banking Module

#### Step 1 - Open the Transaction Screen:

![1 Open Bank Statement.png](https://strapi.suvit.io/uploads/1_Open_Bank_Statement_916fd42dfe.png)

#### Step 2 - Go to **Settings** → **Configurations**:

![2 setings.png](https://strapi.suvit.io/uploads/2_setings_5e8f2210eb.png)

#### Step 3 - Enable Voucher Number:

![3 enable voucher.png](https://strapi.suvit.io/uploads/3_enable_voucher_d5639d4277.png)

### Voucher Number

* One row will be appear for Voucher Number as shown in below screen.

![vocuher number.png](https://strapi.suvit.io/uploads/vocuher_number_7d4c25a0c6.png)

### How to enter Voucher Number

#### Method A

* Click on the cell and enter Voucher Number Number one by one
  ![5 A.png](https://strapi.suvit.io/uploads/5_A_d2bfca37e4.png)
* After entering the data **SAVE** it.

#### Method B

* Make sure you have list of Voucher Number in excel sheet and copy the entire line.
* Click on 1 number below **Sr. No.**
  ![6 1.png](https://strapi.suvit.io/uploads/6_1_953acd393c.png)
* Now use arrow key to move towards below **Supplier No.**
  ![6 3.png](https://strapi.suvit.io/uploads/6_3_82d73f744f.png)
* Paste the data using **CTRL + V**
* Now **Save** the data.
