# We are not able to fetch your GSTIN details.

Facing issues while creating ledgers with GST? Follow our guide to identify common errors and resolve them easily with step-by-step troubleshooting steps.

### If you are getting We are not able to fetch your GSTIN details.

* **Main reason can be GST Portal is Under Maintenance**
* Please try after some time
* OR connect Support Team

### This issue can occur mainly due to two reasons:

#### Reason 1: GST Number Not Updated

* The GST number may not be updated on the GST portal.

#### Reason 2: GST Portal/Website API Issue

* The GST portal or website API could be down. [Click here](https://help.suvit.io/articles/how-to-enable-api-access) for more information.
