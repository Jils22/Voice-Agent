# How to remove a password from a password-protected file?

In this article we will guide you to remove a password from the password protected file in simple steps which ensures the file is ready to be uploaded.

---

### Remove Password from PDF Before Uploading to Suvit

#### Step 1: Open the PDF File

![18image.png](https://strapi.suvit.io/uploads/18image_png_Dec_08_2022_05_24_55_9442_AM_4569aafc77.png)

* **Right-click the PDF** → **Open with** → **Google Chrome**
* **Enter the password** in the prompt.
* **Press Enter** to unlock and view the PDF.

#### **Step 2: Use the Print Option**

![20image-png-Dec-08-2022-05-39-34-6925-AM.png](https://strapi.suvit.io/uploads/20image_png_Dec_08_2022_05_39_34_6925_AM_039541742c.png)

* Once the file is open, locate and click the **Print** button on the right-hand side.

#### **Step 3: Save as PDF**

![21image-png-Dec-08-2022-05-36-21-4025-AM.png](https://strapi.suvit.io/uploads/21image_png_Dec_08_2022_05_36_21_4025_AM_cd3c1bcd80.png)

* In the print dialog, select **Save as PDF** as the destination.
* Click **Save** to generate a new PDF file without a password.

✍ **Upload the New PDF to Suvit**

* Once saved, upload the password-free file to **Suvit**, and it will process successfully.

```
⚠️ **Note:** Avoid using third-party apps or websites to remove passwords, as they may alter the file format.
```
