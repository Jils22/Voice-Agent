# Enable & Enter Supplier/Ref Number in Suvit Banking

Learn to enable and enter Supplier/Reference Numbers in Suvit Banking. This guide explains config settings and two methods for efficient data entry

---

- As of now we are not fetching Supplier/Reference Number from the Bank statement (Pdf & Excel).
- There are two methods to enter Supplier/Reference Number in suvit

### How to Enable Supplier/Reference Number in Banking Module

#### Step 1 - Open the Transaction Screen:

![1 Open Bank Statement.png](https://strapi.suvit.io/uploads/1_Open_Bank_Statement_775ca627f7.png)

#### Step 2 - Go to **Settings** → **Configurations**:

![2 setings.png](https://strapi.suvit.io/uploads/2_setings_fd0ef99760.png)

#### Step 3 - Enable Supplier/Reference Number:

![3 enable cheque number.png](https://strapi.suvit.io/uploads/3_enable_cheque_number_d3ed608960.png)

### Supplier/Reference Number

* One row will be appear for Cheque Number as shown in below screen.
  ![4 supplier no.png](https://strapi.suvit.io/uploads/4_supplier_no_0af7d2539e.png)

### How to enter Supplier/Reference Number

#### Method A

* Click on the cell and enter Supplier/Reference Number one by one

![5 A.png](https://strapi.suvit.io/uploads/5_A_0100bc54d2.png)

* After entering the data **SAVE** it.

#### Method B

* Make sure you have list of Supplier/Reference Number in excel sheet and copy the entire line.
* Click on 1 number below **Sr. No.**
  ![6 1.png](https://strapi.suvit.io/uploads/6_1_9632a02a2c.png)
* Now use arrow key to move towards below **Supplier No.**
  ![6 2.png](https://strapi.suvit.io/uploads/6_2_6940f1eab9.png)
* Paste the data using **CTRL + V**
  ![6 3.png](https://strapi.suvit.io/uploads/6_3_d96509a7c2.png)
* Now **Save** the data.
