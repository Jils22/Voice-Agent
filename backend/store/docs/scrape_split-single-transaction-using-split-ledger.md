# Split a single transaction using split ledger

Now its easy to split one transaction into multiple ledgers from Suvit. The option is beside the ledger column with a "+" symbol.

---

### Overview

In the bank statement, you might come across a transaction that needs to be split into multiple ledgers. To facilitate this, we have the "Split Ledger" option.

#### Step 1: Locate the "+" symbol

![1Split ledger.png](https://strapi.suvit.io/uploads/1_Split_ledger_9aab796afb.png)

* Find the "+" symbol in the **Action** column next to the **Select Ledger** option.
* Refer to the image above for clarity.

#### Step 2: Open the split ledger dialog

![2splitledger1.png](https://strapi.suvit.io/uploads/2splitledger1_c741150481.png)

* Click the "+" symbol to open a dialog box where you can split the transaction.

#### Step 3: Select ledgers and enter amounts

![3splitledger2.png](https://strapi.suvit.io/uploads/3splitledger2_da5b70ef78.png)

* In the dialog box, select the ledgers to split the transaction into.
* Enter the corresponding amounts for each ledger.
* Click the blue "+" button to proceed with the split.

#### Step 4: Ensure the total matches the original amount

![4splitledger3.png](https://strapi.suvit.io/uploads/4splitledger3_7c6eedfaea.png)

* Ensure that the split total equals the original transaction amount.
* If the amounts don’t match, the system will display an error and prevent you from proceeding.
* To discard the split, click **Remove All**.

#### Step 5: Review the split transaction

![5 img.png](https://strapi.suvit.io/uploads/5_img_28333be798.png)

* This image above shows the preview of your split transaction, listing the selected ledgers and corresponding amounts.
* Verify that all details are accurate before confirming.

#### Step 6: Confirm the split and add to the transaction

![5splitledger4.png](https://strapi.suvit.io/uploads/5splitledger4_11b3f94bae.png)

* After confirming that the split amounts are correct, click **Add** to finalize the process.
* The transaction will display only one ledger initially, but after transferring the entry to Tally, all split ledgers will be visible.
