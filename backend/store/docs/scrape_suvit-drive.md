# Suvit Drive

Use Suvit Drive to send and receive documents from clients — in a structured, trackable way. Everything from bank statements to purchase records can be managed easily.

### 📁 Manage Your Client Documents in Suvit Drive

---

#### Step 1: Open Suvit Drive

![1.webp](https://strapi.suvit.io/uploads/1_310031be8d.webp)

* Go to the left menu and click on **Suvit Drive**
* You’ll see folders for every client and their company

→ Each folder shows how many files are already stored
\*\* All files and folders can be download\*\* **Full and module wise**

---

#### Step 2: View Document Transfer (Sent to Clients)

![2.webp](https://strapi.suvit.io/uploads/2_1b11114832.webp)

* Click on the **Document Transfer** tab
* You’ll see:

  → **Transferred Tab**: Files already shared with clients

  → **Pending Tab**: Files that still need to be sent

---

#### Step 3: Track Pending Transfer Requests

![3.webp](https://strapi.suvit.io/uploads/3_ca9dadd5f6.webp)

* View details like:

  → Client and Company Name

  → Task Name

  → Assign Task: Task can be assigned to secondary user

  → Requested Date

  → Document Type (like Bank Statement or Sales/Purchase)
* Use the **Find & Share** button to upload and share the file.

---

#### Step 4: Track Received Documents

![4.webp](https://strapi.suvit.io/uploads/4_11e694b1e1.webp)

* Switch to the **Document Received** tab
* You’ll see all files sent by clients

  → Status: **Action Taken** or **Action Pending**

  → You can mark them as accepted or take necessary steps

---

#### Step 5: Review Pending Document Receives

![5.webp](https://strapi.suvit.io/uploads/5_766ad3740a.webp)

* Switch to the **Pending** tab under **Document Received**
* These are reminders you sent — but haven’t received a document for yet

  → You’ll see “Not Received” in red
  → You can take follow-up action

---

#### ### Step 6: Create New Document Request

![6.webp](https://strapi.suvit.io/uploads/6_cecaaa0095.webp)

* Click on **Create New Request**
* Fill in:

  → Client Name

  → Company Name

  → Assignee (person responsible)

  → Task Name

  → Document Type

  → Due Date (optional)

![7.webp](https://strapi.suvit.io/uploads/7_1a3a398c79.webp)

* Click **Save** to generate a request. The client will get a notification and can upload the file.
