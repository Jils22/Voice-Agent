# How to update Suvit Application?

To make processes smooth and versatile, Suvit application is updated at various intervals. It is essential for you to use the latest version for better experience.

### Automatic Update

* You will get automatic notification to **Update your Application**

**OR else**,

* **Logout** the **Suvit Desktop Application** and then you will receive the **Auto Update** Option
* **Click** on **Auto Update** and wait for a while application will restart automatically.

### Manual Update

* If the app does not update automatically, follow the steps below to manually uninstall and reinstall the application.

#### Step A: Uninstall the Suvit Desktop Application

![2_image(COPY).png](https://strapi.suvit.io/uploads/2_image_COPY_a78ff0bfce.png)

* Go to **Windows Search** and type **"Control Panel"**.

![3_image.png](https://strapi.suvit.io/uploads/3_image_a0667c1954.png)

* In **Control Panel**, click on **Programs and Features**.

![4_image.png](https://strapi.suvit.io/uploads/4_image_7a66b36877.png)

* Search for the **Suvit Desktop Application** in the list **right-click** and select **Uninstall**.

#### Step B: Download and Install the Latest Version

* Visit the Suvit Web portal and sign in to [Suvit.io](https://www.suvit.io/)

![dash.png](https://strapi.suvit.io/uploads/dash_ed81526ff3.png)

* Click on **"Help & Resources"** on the dashboard.
* Then click on **"Download"**
  + By Default **64-bit version** will be get **downloaded**.

#### Complete the Update

* **Double Click** on the **Application** to install.

#### You may find this useful:

* If you encounter the error "Looks like you're using an older Suvit Tally Connector app version. Please update your application [click here](https://help.suvit.io/articles/looks-like-you-re-using-an-older-version-of-the-suvit-tally-connector-app-please-update-your-application) for the solution.
