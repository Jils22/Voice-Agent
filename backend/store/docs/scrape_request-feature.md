# Request Feature

Suvit's "Request Feature" option lets you suggest new features to improve your workflow. Submit ideas and the team will review them for future updates.

### **Navigation**

* Login into [Suvit](https://in.suvit.io/signIn).
* Click on **Explore Now** under **Data Entry Automation**.

#### Step 1 - Open the Request Feature Page

![1.png](https://strapi.suvit.io/uploads/1_5d3da6eaed.png)

* **1** → Go to the **Learn More** → **Request Feature** or by visiting [this link](https://in.suvit.io/da/request-feature).

#### Step 2 - Fill in the Required Details

![2.png](https://strapi.suvit.io/uploads/2_5bf2c3d38d.png)

* **2** → Give **Heading** of your Request
* **3** → Select **Module** type in which you have to request

![3.png](https://strapi.suvit.io/uploads/3_364ab5b369.png)

* **4** → Select The **Tag**. It can be **New, Existing(old)** or **Other** request

![4.png](https://strapi.suvit.io/uploads/4_073d051430.png)

* **5** → Enter a **clear and concise description** of the feature you need. Mention the **purpose** and **how it will help** in your workflow.
* **6** → Attach a **Screenshot** for better clarification
* **7** → Click on **Save** to send your request for review.

![5.png](https://strapi.suvit.io/uploads/5_79a547ff2b.png)

* **8** → You can verify your **Request** here.
