# Re-select ledgers in bank statement

Learn how you can overwrite the ledger selected, given that the entries are yet to be sent in the Tally.

---

### Re-select Ledgers in Bank Statement

#### Step 1: Identify the Need for Ledger Change

* If you have already selected and saved ledgers for transactions, they are ready to be sent to **Tally**. However, if you need to change the ledgers (provided the transactions haven't been sent to **Tally** yet), you can do so by following the same ledger selection process.

#### Step 2: Understanding Ledger Modification Rules

* You can modify the selected ledgers at any time, but note that once a ledger is selected and saved, it cannot be left empty.

#### Step 3: Choose a Ledger Selection Method

* To re-select ledgers, you have two options:

**A.** **Bulk ledger selection**, as shown in the image below.  
![1banking24.png](https://strapi.suvit.io/uploads/1banking24_427e387194.png)

```
    **1.** Select the required transactions.   
    **2.** In the **"Ledger"** section, use **bulk operations** to assign the correct ledger,             as shown above.   
    **3** Click **"Save"** to confirm and apply the changes.
```

**B.** **Individual ledger selection**

* If you prefer, you can manually update each ledger for better accuracy.

![2banking25.png](https://strapi.suvit.io/uploads/2banking25_0fe57f7ff6.png)

* Select the appropriate ledger from the dropdown list.
* Click **Save** to apply the changes.
