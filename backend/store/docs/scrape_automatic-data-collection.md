# Data Collection

Enable automatic client data collection in Suvit, accessible anytime, anywhere. Simplify workflows with real-time access to financial data on the go.

---

### Data Collection.

* Suvit's data collection feature is designed to automate the process of gathering and inputting financial data into your accounting software. It primarily focuses on automating data entry from various sources.

#### Step 1. Login

![1 data collection.png](https://strapi.suvit.io/uploads/1_data_collection_4cf82da240.png)

* Sign into [Suvit](https://www.suvit.io/).
* Then go to [Data Collection](https://in.suvit.io/data-collection-frequency).

#### Step 2. Select Reminder type

![2.png](https://strapi.suvit.io/uploads/2_657f2fe643.png)

* Go to **Set Frequency** → **Reminder type**

![3 manual set.png](https://strapi.suvit.io/uploads/3_manual_set_ba80a190ff.png)

* You can select **Auto or Manual** from the menu for reference use below image.

#### Step 3. Select Company

![4 save and WA.png](https://strapi.suvit.io/uploads/4_save_and_WA_55f0fd0393.png)

* **Select the respected company** on which you want to send the data and click on Manual reminder.

#### Step 4. Scan WhatsApp

![5 Scan WA.png](https://strapi.suvit.io/uploads/5_Scan_WA_b53b8b9abf.png)

* Scan your **WhatsApp Application** from which number you would like to send the WhatsApp Reminder.

```
Warning: Kindly Logout the Web-WhatsApp if you are using in the same browser.
After connecting with Suvit. You can re use the Web WhatsApp
```

* You don't need to **scan the WhatsApp QR code** multiple times unless prompted by the app.

#### Step 5. WhatsApp connected

![6 Conecting WA.png](https://strapi.suvit.io/uploads/6_Conecting_WA_248719f049.png)

* After **Scanning** system will connect your WhatsApp account with Suvit.

#### Step 6. Select Template

![7.png](https://strapi.suvit.io/uploads/7_464771b61b.png)

* Once you get connected with the Account, Suvit will provide the **pre-defined template**.

#### Step 7. Select Transaction type

![8 Select desired Month and module.png](https://strapi.suvit.io/uploads/8_Select_desired_Month_and_module_ffdeb6ce13.png)

* In this template you can select the time duration and **Transaction type** (Banking, Sales & Purchase)

How Client will receive the message

1. Your client will receive the message as below given image. Client can simply click on the link or else he/she can reply to this message.

![9 client.jpg](https://strapi.suvit.io/uploads/9\_client\_cf6a27168d.jpg)

2. Client will be diverted to upload part

![10 client.jpg](https://strapi.suvit.io/uploads/10\_client\_f9498bc56a.jpg)

3. You can select requested file.

![11 client.jpg](https://strapi.suvit.io/uploads/11\_client\_d4b41f9022.jpg)

12 Click on Upload button to upload the file.

![12 client.jpg](https://strapi.suvit.io/uploads/12\_client\_597e42a9d1.jpg)

13 You will receive Successful message once the file is uploaded.

![13 client.jpg](https://strapi.suvit.io/uploads/13\_client\_792500aaac.jpg)

#### Step 8. Verification

![14 fie select.png](https://strapi.suvit.io/uploads/14_fie_select_5b61ce53e9.png)

* Once document is uploaded by the client. one can check the file in respectively tabs and **verify** it.
  From right side actions one can view the file, download fie, accept and reject the file.
* If you accept the request that particular document you can cross check in Bulk Upload section.
