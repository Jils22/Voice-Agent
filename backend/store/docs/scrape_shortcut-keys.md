# Shortcut Keys in Suvit

This FAQ lists shortcut keys in Suvit’s Banking and Sales/Purchase modules—learn how to open pages, save entries, fetch ledgers, and sync data with Tally.

### FAQ: Shortcut Keys in Suvit Banking

#### Open Transaction page

* Go to -> rawer ( **CTRL + M**)
  ![1 open drawr.png](https://strapi.suvit.io/uploads/1_open_drawr_117036e885.png)

#### Short-cut Keys

![2 short cut keys.png](https://strapi.suvit.io/uploads/2_short_cut_keys_28592c569e.png)

#### 1. **What is the shortcut key to save a transaction?**

* **Answer**: The shortcut key to save a transaction is **CTRL + S**.

#### 2. **How can I fetch a ledger using shortcut keys?**

* **Answer**: To fetch a ledger, use the shortcut key **CTRL + L**.

#### 3. **What is the shortcut key to sync data to Tally?**

* **Answer**: The shortcut key to sync data to Tally is **ALT + T**.

#### 4. **How can I create a new ledger using shortcut keys?**

* **Answer**: To create a new ledger, use the shortcut key **ALT + C**.

#### 4. **How can I create a new Stock Item using shortcut keys?**

* **Answer**: To create a new ledger, use the shortcut key **ALT + I**.
* This is applicable only on with stock item transactions.
