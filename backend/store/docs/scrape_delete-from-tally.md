# Delete Transaction (entry) from Tally using Suvit

Learn to delete transactions from Tally using Suvit. Only Suvit-synced data is removed, keeping other records safe and simplifying the deletion process.

### Follow the Steps Below

* Navigate to Transaction Screen
* Open the file form which Transaction (entry) need to be deleted.

#### Step 1 - Select your entry

![1.png](https://strapi.suvit.io/uploads/1_3af2e3ca89.png)

* **1** → Select your **Transaction**
* **2** → Click on **Delete** Button

#### Step 2 - Delete from Tally

![2.png](https://strapi.suvit.io/uploads/2_6621e9c6ea.png)

* **3** → Select **Delete From Tally**
* **4** → Click on **Delete** Button

#### Step 3 - Wait for the confirmation message

![3.png](https://strapi.suvit.io/uploads/3_330e4887db.png)

* **6** → After the message appears, the **selected transactions** have been **successfully deleted** from Tally.

```
Only the data sent from Suvit will be deleted from Tally. No other data will be affected.
```
